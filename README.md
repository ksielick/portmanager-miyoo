# portmaster-miyoo

Test repo for a port manager on the Miyoo Mini (OnionOS), PortMaster-like: it lists, installs
and updates native Miyoo ports, downloading each one from its author's GitHub releases. No
port zips are hosted here, only a catalog of where they are released.

Nothing is built yet. The plan (PortMaster-New analysis, catalog format, steps) is in
`miyoo/PORT_MANAGER.md` of github.com/ksielick/redriver2-miyoo; the first step is the PC
script that grows out of its `miyoo/tools/update_miyoo64.sh`.
