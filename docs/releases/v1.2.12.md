**New game: Sensible World of Soccer (OpenSWOS)**

Sensible World of Soccer, rebuilt in C from the original Amiga game by the OpenSWOS project, ported to the Miyoo Mini by sakya. It is in the new **Sports** category of the Ports list.

You need your own copy of *Sensible World of Soccer 96/97* (the PC version from GOG, or the Amiga version). On a computer, run OpenSWOS Setup (openswos.net/install) with your copy once: it makes an `assets` folder. Copy that whole folder into `Roms/PORTS/Games/OpenSWOS/`. The game's page in Port Manager tells you when it's still missing.

**Also changed**

- Ports whose download has only an `App` folder and no shortcut of their own now get a shortcut and a picture in the Ports list. Older Port Manager versions would install Sensible World of Soccer without a shortcut, so update Port Manager first.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
