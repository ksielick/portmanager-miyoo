**What's new**

- **Faster update checks.** Checking your games for updates is about 3 times faster, and the screen shows which game is being checked.
- **Clearer game pages.** A game's page now shows at a glance whether it is installed and exactly which file you need to add, and where. Press **Select** for all the details.
- **Help for new players.** With no games installed yet, the first screen shows simple steps for getting your first one.
- **Port Manager updates itself first.** When you check for updates, Port Manager updates itself and then checks your games.
- **Simpler progress screen.** One progress bar per game, and it stays at "100% done" when the game is finished.

**Safer**

- Removing a game but keeping its data never deletes your ROM or your saves.
- Restoring a backup also puts the right version number back.
- Port Manager never offers to "update" to an older version.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
