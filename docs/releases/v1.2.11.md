**Fixed: downloads from GitHub stopped at 0%**

Since November 2026 installing or updating a game could stop at "1/3 Downloading 0%", then end with "download failed". It hit games from other authors' GitHub pages (for example cacuracaptors' Zelda - Ocarina of Time) and Port Manager's own update.

The cause: Port Manager downloaded files with Onion's built-in `wget`, and that old program can no longer connect to github.com (checking for updates still worked). Port Manager now downloads everything with Onion's `curl`, the program Onion's own OTA update uses for the same reason. Nothing new to install: `curl` is part of Onion.

**Also changed**

- When a download fails, the message now says why (for example "Could not resolve host" or "Connection timed out"), on the screen and in `App/PortManager/log.txt`.
- A large game on slow Wi-Fi is no longer stopped after a fixed time: a download is given up only when nothing arrives for 60 seconds.

**Updating from v1.2.10 or older:** the update itself is downloaded by your current Port Manager, which still uses the old `wget`. If **Y** shows the update but it ends with "Port Manager: download failed", install this version by hand once: download `PortManager-Miyoo.zip` on a computer and copy its `App` and `Roms` folders to your SD card, replacing the files. Your games, saves, backups and `tokens.txt` stay. Later updates work from Port Manager again.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update (or copy it by hand, see above).

Copyrighted files (ROMs, game data) are never downloaded or hosted.
