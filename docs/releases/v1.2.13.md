**Missing game files: a message instead of a silent return to the menu**

Some games need files from your own copy, such as the `assets` folder for Sensible World of Soccer. Until now, starting such a game from the Ports list without them only flashed the screen and went back to the menu. Now the game's shortcut checks first: if anything is missing, a **GAME FILES MISSING** panel lists it, and the game's page in Port Manager tells you how to get it.

This works for shortcuts Port Manager makes itself (today: Sensible World of Soccer). A game you installed before gets the new shortcut when you install or update it again.

**Also fixed**

- Sensible World of Soccer v0.4.0 can be installed and updated again. Its download got a new name, which Port Manager did not recognise ("the release has no matching file"). This was a catalog fix, so it already works in older versions.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
