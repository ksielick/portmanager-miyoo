**Games started with Start now show up in Onion's recently played list**

Since v1.2.6 you can press **Start** on a game's page in Port Manager to play it. Now the game also goes on top of Onion's recently played list (Recents), just as when you start it from the Ports list, so you can start it again from there.

If you have hidden the recently played list in Onion, it goes into the hidden list and shows up when you turn the list back on.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
