**New: press Start on a game's page to play it**

When a game is installed and its game files are in place, its page in Port Manager now shows **Start: play**. Press **Start** and Port Manager closes and the game starts right away. When you quit the game, you are back in Onion's menu, as after any game.

The game also goes on top of Onion's recently played list (Recents), just as when you start it from the Ports list. If you have hidden that list in Onion, the game shows up there when you turn the list back on.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
