**New games**

Six new games are in Port Manager since v1.2.9:

- **Quake** (TyrQuake) and **Quake II** (FPS). You need your own copy of the game's data (Steam or GOG); each game's page says which files go where.
- From mr-finster's miyoo64: **Banjo-Kazooie** (Platform), **Pilotwings 64** (Simulation) and **The New Tetris** (Puzzle games). Their author calls them test versions (Beta). Each needs your own USA ROM, saved as `rom.z64` in the game's folder: the game's page names the exact version and its checksum.
- **Zelda - Ocarina of Time** from cacuracaptors (Action): a second Ocarina of Time port, with its own folder and saves, next to mr-finster's. It needs the USA **1.1 (Rev A)** ROM; any file name works, zipped too. The first start builds the game data (a few minutes). Your European ROM, if you add it, gives German and French.

Port Manager itself works as in v1.2.9: this version brings the new list of games, so a fresh install has them from the start.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
