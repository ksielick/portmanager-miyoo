**New games**

Two new N64 games from miyoo64, both need your own cartridge dump (the game's page says which one):

- **Majora's Mask** (Action): a test version from its author, the whole game.
- **Harvest Moon 64** (Simulation, a new category): run your farm, day by day.

**What's new**

- **A clearer update check.** Pressing **Y** now goes step by step: Port Manager first, then the list of games (one line with a bar, then how many games are new or changed), then your games.
- **After Port Manager updates itself it restarts first**, and only the new version checks the list of games and your games.
- **No list of games on the card?** Port Manager no longer stops with an error: it downloads the list right away.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
