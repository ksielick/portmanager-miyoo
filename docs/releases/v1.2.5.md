**Fix: "Remove, keep data" no longer deletes game videos and saves**

Removing a port with "keep data" could delete files that belong to you, when they were not in the folders Port Manager knew about:

- **Tomb Raider:** the game's videos (`Tomb Raider 1/FMV/`) were deleted, so the cutscene videos stopped playing. The save file (`savegame.dat`) was at risk too.
- Videos (`.RPL`, `.STR`, `.MP4`, `.AVI`...) and `.dat` files are now kept in every port, and folders such as `FMV`, `Movies`, `Video`, `Saves`, `Music` and `Data` are kept wherever they are in the game's folder, not only at its top.
- Each file that "remove" deletes is now listed in Port Manager's log.

**Videos missing in Tomb Raider?** They are not in any backup, so they have to be unpacked again: copy `GAME.GOG` from your GOG Tomb Raider 1 folder into `Roms/PORTS/Games/OpenLara/Tomb Raider 1/` and start the game. It unpacks only what is missing, here the videos (about a minute), and deletes `GAME.GOG`. Your saves stay.

**Install for the first time:** download `PortManager-Miyoo.zip`, then copy its `App` and `Roms` folders to your SD card. See the [instructions](https://github.com/ksielick/portmanager-miyoo#install-first-time).
**Already installed:** press **Y** in Port Manager and accept the update.

Copyrighted files (ROMs, game data) are never downloaded or hosted.
